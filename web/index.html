서버별 SSH/SFTP 원격 로그 조회

JEUS · WebtoB · WAS · 웹 서버 · Linux · 사용자 정의

선택한 서버에 SSH/SFTP로 연결합니다. 실제 로그 경로는 서버 설정에서 확인하세요.

접속 대상 목록은 현재 브라우저 세션 메모리에만 보관하고 종료 시 사라집니다. 비밀번호는 대상 정보에 저장하지 않습니다. 서로 다른 서버에도 각각 SSH/SFTP 조회 권한이 필요합니다.

서버 자격 증명은 이 세션에서만 사용하며 파일을 저장하지 않습니다.
최근 로그를 조회하면 HTTP 상태와 오류·경고 수를 표시합니다. 

 

 

  
접속 준비 → TCP/SSH → 서버 지문 → 사용자 인증 → SFTP → 파일 확인 → 읽기 → 종료
   
   
  

  
연결을 시작하면 단계별 진단 기록이 실시간으로 표시됩니다.

  
진단 기록은 현재 브라우저 메모리에만 보관합니다. 비밀번호·인증 토큰·로그 원문은 기록하지 않습니다. SSH 연결은 매 조회마다 생성하고 조회 종료 시 닫습니다.

 

 
선택한 서버의 SSH/SFTP 서비스(일반적으로 22번 포트)에 접속하며 WebtoB/JEUS의 HTTP 또는 관리 포트에 직접 접속하지 않습니다. SFTP 프로토콜로 일반 텍스트 로그 파일의 끝부분만 읽습니다. WebtoB 접속·에러·시스템 로그처럼 서로 다른 파일은 경로를 지정하여 조회합니다. 원격 쉘 실행, 업로드, 삭제, 권한 변경 기능은 제공하지 않습니다. 서버 계정 권한 자체는 애플리케이션이 제한할 수 없으므로 서버에서도 조회 전용 계정을 사용해야 합니다. 이 화면의 조회는 전체 파일 인덱싱이나 장애 확정 진단이 아닙니다.
